## Tyre Class — What I learned

Built the Tyre class with compound validation, grip degradation, and pit strategy.

Key formula:
  wear per lap = 0.01 × track_roughness × wear_rate

Monza (roughness=0.4) on softs (wear_rate=2.0):
  = 0.008 grip lost per lap
  = pit on lap 63

Lesson: when code produces no output, do the math first.
The code was correct — the threshold just needed more laps to trigger.

Bugs I made and fixed:
- VALID_COMPOUND: instead of = (annotation vs assignment)
- grip_level as a constructor parameter instead of deriving it from compound
- Properties named _grip_level instead of grip_level (private vs public)
- Missing self in add_lap method
- self.grip instead of self.grip_level in is_critical and should_pit
